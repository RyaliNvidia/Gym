## In-process rollout API

To run rollouts from Python against Gym servers that are already running, call
`RolloutCollectionHelper.preprocess_examples` to select, route and repeat rows, then pass the returned rows to
`RolloutCollectionHelper.run_examples`, which sends each row to its agent and returns awaitables that resolve to
`(row, result)` pairs.
`gym eval run` uses the same steps.

These two methods are a supported API. Their signatures change only additively: a new parameter is optional
and keyword-only, and a parameter is deprecated before it is removed or renamed.
